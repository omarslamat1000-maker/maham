# الأمان والخصوصية

## نموذج التهديد

التطبيق ثابت بلا خادم. البيانات في IndexedDB على جهاز المستخدم. أي شخص يملك وصولًا لنفس حساب المتصفح يمكنه قراءة البيانات —
**ملفا العمل ليسا مصادقة**. لحماية البيانات استخدم حساب نظام تشغيل/متصفح محمي بكلمة مرور.

## الضوابط المطبقة

| المجال | الضابط |
| --- | --- |
| XSS | React يرمّز المخرجات؛ `dangerouslySetInnerHTML` ممنوع بقاعدة ESLint؛ CSP صارمة في الإنتاج (`script-src 'self'`, `object-src 'none'`, `frame-src 'none'`, `connect-src 'self'`) |
| الملفات المرفوعة | قائمة أنواع مسموحة وحد للحجم؛ الفيديو كرابط فقط؛ HTML/SVG لا تُعرض داخل أصل التطبيق؛ التنزيل بنوع `application/octet-stream` وأسماء منظّفة |
| الروابط | http/https فقط (`safeUrl`)، وتُفتح بـ `noopener noreferrer`؛ `referrer: no-referrer` |
| التحقق من المدخلات | مخططات Zod لكل الإدخالات ولملفات النسخ الاحتياطي وردود الذكاء الاصطناعي |
| تصدير CSV | تحييد حقن الصيغ (`=`, `+`, `-`, `@`) |
| النسخ الاحتياطي | تشفير AES-256-GCM عبر Web Crypto مع PBKDF2-SHA-256 (600,000 تكرار، ملح عشوائي)؛ تحقق سلامة SHA-256؛ ملفات النسخ مستبعدة في `.gitignore` |
| الأسرار | لا مفاتيح API ولا Tokens في الكود أو التخزين المحلي أو ملفات النشر |
| السجلات | `no-console` في ESLint؛ معالج الأخطاء لا يسجّل بيانات المهام؛ رسائل الأخطاء للمستخدم لا تكشف تفاصيل داخلية |
| CI/CD | صلاحيات دنيا، إجراءات مثبتة بـ SHA، `persist-credentials: false`، `npm audit` لحزم الإنتاج، Dependabot |

## حالة تدقيق الحزم

- حزم الإنتاج: `npm audit --omit=dev` ← **0 ثغرات** (عند الإصدار 1.0.0).
- حزم التطوير: توجد تنبيهات متوسطة في أدوات البناء (glob/minimatch عبر workbox-build وtypescript-eslint) لا تُشحن للمتصفح؛ تُتابع عبر Dependabot.

## الإبلاغ عن ثغرة

افتح Security Advisory خاصًا في المستودع (Security → Advisories) بدل Issue عام.
