# الأمان والخصوصية

## نموذج التهديد

التطبيق ثابت بلا خادم. البيانات في IndexedDB على جهاز المستخدم.

### تسجيل الدخول والتشفير على القرص

**البيانات مشفّرة داخل المتصفح (at-rest).** بدون كلمة مرور صحيحة لا يمكن قراءة المحتوى، حتى لمن يفتح ملفات المتصفح أو أدوات المطوّر.

```
كلمة المرور ──PBKDF2-SHA-256 (600,000 تكرار + ملح 16 بايت)──► P
P ──HKDF──► بصمة تحقق (تُخزَّن)        P ──HKDF──► مفتاح تغليف KEK (لا يُخزَّن)
المفتاح الرئيسي (256-bit عشوائي) ──AES-256-GCM بـ KEK──► wrappedKey (يُخزَّن لكل ملف عمل)
المفتاح الرئيسي ──HKDF──► مفتاح السجلات (AES-256-GCM) + مفتاح الفهرسة العمياء (HMAC-SHA-256)
```

| مشفّر | غير مشفّر (ضروري للعمل) |
| --- | --- |
| المهام، الخطوات، التحديثات، المخرجات وإصداراتها، **محتوى الملفات**، قوائم التحقق، القرارات، الأفكار، التصنيفات، التنبيهات، سجل النشاط | أسماء ملفَي العمل وألوانهما وبصمات كلمات المرور والمفتاح المغلّف (لازمة لشاشة الدخول) |
| | الإعدادات العامة (أيام الاستحقاق، المظهر…) |
| | المعرّفات العشوائية (UUID) وروابطها (مثل: أي خطوة تتبع أي مهمة) وعدد السجلات |

- المفتاح الرئيسي غير المغلّف يبقى **في الذاكرة فقط** ويُمسح عند الخروج أو القفل التلقائي أو إعادة تحميل الصفحة.
- مفتاح منع تكرار التنبيهات يُخزَّن كفهرس أعمى (HMAC) بدل نصه.
- المكتبات: `@noble/ciphers` و`@noble/hashes` (مدققة أمنيًا، متزامنة لتعمل داخل معاملات IndexedDB) + Web Crypto لـ PBKDF2.
- إيقاف مؤقت متصاعد بعد 5 محاولات خاطئة (30 ث حتى 15 د)، وقفل تلقائي بعد عدم النشاط (افتراضي 15 دقيقة).
- **المستخدم الثاني** يُفعَّل بكلمة مرور مؤقتة يعيّنها المستخدم الذي سجّل دخوله (تغليف المفتاح بها)، ويُلزم بتغييرها عند أول دخول.
- **نسيان كلمتي المرور معًا = فقدان البيانات المحلية نهائيًا.** الاستعادة فقط من نسخة احتياطية.

**الحدود:** ليست مصادقة خادمية. من يملك جهازك وهو مفتوح على التطبيق بعد الدخول يرى البيانات. البرمجيات الخبيثة على الجهاز قد تلتقط كلمة المرور.
النسخ الاحتياطية غير المشفّرة تحتوي البيانات كنص صريح — التشفير مفعّل افتراضيًا عند التصدير.

## الضوابط المطبقة

| المجال | الضابط |
| --- | --- |
| XSS | React يرمّز المخرجات؛ `dangerouslySetInnerHTML` ممنوع بقاعدة ESLint؛ CSP صارمة في الإنتاج (`script-src 'self'`, `object-src 'none'`, `frame-src 'none'`, `connect-src 'self'`) |
| الملفات المرفوعة | قائمة أنواع مسموحة وحد للحجم؛ الفيديو كرابط فقط؛ HTML/SVG لا تُعرض داخل أصل التطبيق؛ التنزيل بنوع `application/octet-stream` وأسماء منظّفة |
| الروابط | http/https فقط (`safeUrl`)، وتُفتح بـ `noopener noreferrer`؛ `referrer: no-referrer` |
| التحقق من المدخلات | مخططات Zod لكل الإدخالات ولملفات النسخ الاحتياطي وردود الذكاء الاصطناعي |
| تصدير CSV | تحييد حقن الصيغ (`=`, `+`, `-`, `@`) |
| النسخ الاحتياطي | تشفير AES-256-GCM عبر Web Crypto مع PBKDF2-SHA-256 (600,000 تكرار، ملح عشوائي)؛ تحقق سلامة SHA-256؛ ملفات النسخ مستبعدة في `.gitignore` |
| تسجيل الدخول والتشفير | PBKDF2 + HKDF، تشفير مغلّف AES-256-GCM لكل السجلات والملفات، مقارنة بزمن ثابت، إيقاف مؤقت، قفل تلقائي، المفتاح في الذاكرة فقط |
| الأسرار | لا مفاتيح API ولا Tokens في الكود أو التخزين المحلي أو ملفات النشر |
| السجلات | `no-console` في ESLint؛ معالج الأخطاء لا يسجّل بيانات المهام؛ رسائل الأخطاء للمستخدم لا تكشف تفاصيل داخلية |
| CI/CD | صلاحيات دنيا، إجراءات مثبتة بـ SHA، `persist-credentials: false`، `npm audit` لحزم الإنتاج، Dependabot |

## حالة تدقيق الحزم

- حزم الإنتاج: `npm audit --omit=dev` ← **0 ثغرات** (عند الإصدار 1.2.0).
- حزم التطوير: توجد تنبيهات متوسطة في أدوات البناء (glob/minimatch عبر workbox-build وtypescript-eslint) لا تُشحن للمتصفح؛ تُتابع عبر Dependabot.

## الإبلاغ عن ثغرة

افتح Security Advisory خاصًا في المستودع (Security → Advisories) بدل Issue عام.
