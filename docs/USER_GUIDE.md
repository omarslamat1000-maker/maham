# دليل المستخدم — مهام | MAHAM

## البداية

1. افتح التطبيق لتظهر **صفحة تسجيل الدخول**. اختر ملفك: **مدير النظام** أو **المدير الثاني**.
   - أول دخول: أنشئ كلمة مرور (8 أحرف على الأقل، حروف وأرقام).
   - بعدها: أدخل كلمة المرور ثم «تسجيل الدخول».
   - بعد 5 محاولات خاطئة تتوقف المحاولات مؤقتًا.
2. يُنسب كل إجراء في السجل لمن سجّل الدخول. للتبديل: قائمة الحساب (أعلى الشاشة) ← **تسجيل الخروج** ثم ادخل بالملف الآخر.
3. يُقفل التطبيق تلقائيًا بعد 15 دقيقة من عدم النشاط (قابل للتغيير من **الإعدادات ← الأمان وتسجيل الدخول**)، وكذلك عند إغلاق التبويب.
4. **نسيت كلمة المرور؟** يعيد المستخدم الآخر تعيينها من **الإعدادات ← الأمان وتسجيل الدخول**، فتنشئ كلمة جديدة عند دخولك. إن نسي الاثنان: «نسيت كلمة المرور؟» ← حذف جميع البيانات ثم استيراد نسخة احتياطية.
5. ثبّت التطبيق (اختياري): **الإعدادات ← تثبيت التطبيق**، أو من قائمة المتصفح. على iPhone: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

> ⚠️ بياناتك على هذا المتصفح فقط. تسجيل الدخول يحمي فتح التطبيق، لكن البيانات نفسها غير مشفّرة داخل المتصفح — احمِ حساب جهازك. صدّر نسخة احتياطية (مشفّرة) أسبوعيًا على الأقل.

## إنشاء مهمة

- اضغط **+ مهمة جديدة** (أو المفتاح <kbd>N</kbd>، أو الزر الأخضر في منتصف الشريط السفلي على الجوال).
- العنوان إلزامي فقط. اختر «حفظ المهمة» أو «حفظ وفتح التفاصيل».
- اضغط <kbd>/</kbd> للبحث السريع.

## صفحة تفاصيل المهمة

| التبويب | الاستخدام |
| --- | --- |
| المعلومات العامة | تعديل البيانات والحالة (جديدة/قيد التنفيذ) ونسبة الإنجاز اليدوية مع السبب |
| الخطوات | أضف خطوات بأوزان. غيّر الإنجاز بالمؤشر أو الحالة؛ تُحسب نسبة المهمة تلقائيًا |
| التحديثات | سجّل ما أُنجز والتحديات والإجراء التالي ومرفقًا اختياريًا |
| المخرجات | ارفع الملفات أو أضف روابط. «رفع إصدار جديد» يحتفظ بالإصدارات السابقة. حدّد المخرج النهائي |
| التسليم والاعتماد | قائمة التحقق ثم: تقديم للمراجعة ← اعتماد أو طلب تعديلات (بسبب) ← إعادة فتح عند الحاجة |
| سجل النشاط | كل تغيير بمن نفّذه ومتى |

### قواعد الإكمال
لا تكتمل المهمة إلا بالاعتماد، ولا يُسمح بالاعتماد قبل: إنجاز كل الخطوات، وتحديد مخرج نهائي، واستيفاء المتطلبات اليدوية الإلزامية.

## المهام العاجلة
تعرض المتأخرة، والعالية/العاجلة، والقريبة من الاستحقاق، وغير المحدثة. غيّر المدة وأيام الركود من الإعدادات.

## بنك الأفكار
سجّل فكرة بالقيمة المتوقعة والأولوية، ثم «تحويل إلى مهمة» — تبقى الفكرة محفوظة مع رابط للمهمة.

## التقويم
عرض شهري/أسبوعي لتواريخ البداية (▶) والاستحقاق (●). الألوان: أخضر مكتملة، أحمر متأخرة، كهرماني عاجلة.

## التقارير
اختر الفترة والفلاتر. صدّر **CSV** أو **Excel** أو **PDF** (يفتح نافذة الطباعة — اختر «حفظ بصيغة PDF»).

## التنبيهات
تُولَّد عند فتح التطبيق وكل 5 دقائق. لتنبيهات النظام اضغط «تفعيل» في صفحة التنبيهات. لا تصل التنبيهات والتطبيق مغلق بالكامل.

## MAHAM AI
1. اختر الإجراء (مثل «اقتراح خطوات التنفيذ») والمهمة.
2. «إنشاء البرومبت» ← «نسخ البرومبت» ← «فتح Gemini» والصق.
3. انسخ رد Gemini والصقه في الخانة الثانية ← «تحليل الرد».
4. راجع النتيجة، اختر العناصر، ثم «تطبيق» — لا شيء يُطبق دون تأكيدك.

> نسخ البرومبت إلى Gemini يرسل بيانات المهمة إلى Google. خيار «إخفاء أسماء المستخدمين» مفعّل افتراضيًا.

## النسخ الاحتياطي والنقل بين الأجهزة
- **تصدير:** الإعدادات ← النسخ الاحتياطي ← اختر تضمين المرفقات و(اختياريًا) التشفير بكلمة مرور ← تصدير.
- **استيراد:** اختر الملف ← راجع الملخص ← **دمج** (آمن، يحتفظ بالأحدث) أو **استبدال كامل** (يحذف الحالي).
- كلمة مرور التشفير لا يمكن استعادتها.

## المحذوفات
حذف المهمة منطقي. استرجعها أو احذفها نهائيًا من **الإعدادات ← المهام المحذوفة**.
