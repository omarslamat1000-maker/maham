# مهام | MAHAM

**نظّم مهامك، تابع تقدمك، أنجز بذكاء**

نظام ذكي لإدارة المهام والمخرجات — عربي أولًا، يعمل دون اتصال، ويُستضاف بالكامل على GitHub.

## ما هو «مهام»؟

تطبيق ويب تقدمي (PWA) لإدارة المهام الشخصية والمهنية لمستخدمَين اثنين، يجمع بين: التخطيط التنفيذي بخطوات موزونة،
متابعة الإنجاز، مسار تسليم واعتماد، بنك الأفكار، إدارة المخرجات والملفات، التقويم، التنبيهات، التقارير، ومساعد ذكي مع Google Gemini.

> **مهم:** جميع البيانات تُحفظ داخل متصفحك (IndexedDB) على جهازك فقط. لا يوجد خادم ولا مزامنة تلقائية بين الأجهزة.
> استخدم النسخ الاحتياطي من الإعدادات بانتظام.

## المزايا

| الوحدة | الوصف |
| --- | --- |
| تسجيل الدخول والتشفير | صفحة دخول بهوية التطبيق، وتشفير AES-256 لكل البيانات والملفات على الجهاز بمفتاح لا يُفتح إلا بكلمة مرور أحد الملفين |
| لوحة القيادة | 10 مؤشرات حية قابلة للنقر تفتح قوائم مفلترة، أبرز المهام، آخر التحديثات، أسباب التعثر |
| الإنشاء السريع | زر «+ مهمة جديدة» من كل الصفحات أو مفتاح <kbd>N</kbd> |
| تفاصيل المهمة | معلومات عامة، خطوات موزونة، تحديثات (خط زمني)، مخرجات بإصدارات، تسليم واعتماد، سجل نشاط |
| الإنجاز المرجح | `SUM(وزن × إنجاز) / SUM(الأوزان)` مع تطبيع وتعديل يدوي موثّق بالسبب |
| دورة الحياة | جديدة → قيد التنفيذ → مكتملة، ومسار تسليم مستقل (تقديم / طلب تعديلات / اعتماد / إعادة فتح) |
| المهام العاجلة | المتأخرة، عالية الأولوية، قريبة الاستحقاق، غير المحدثة — مع فلاتر |
| بنك الأفكار | تسجيل، أرشفة، وتحويل إلى مهمة مع الاحتفاظ بالفكرة |
| المخرجات | Word, PowerPoint, Excel, PDF, HTML, صور، روابط فيديو؛ تنزيل، استبدال، سجل إصدارات |
| التقارير | معدل الإنجاز، المخطط مقابل الفعلي، الأداء حسب المستخدم/التصنيف، التأخير؛ تصدير CSV/Excel/PDF |
| التقويم | عرض شهري وأسبوعي |
| التنبيهات | مركز داخلي + تنبيهات المتصفح عند الإذن |
| MAHAM AI | 10 إجراءات ذكية عبر Gemini مع تحقق من الرد وموافقة بشرية قبل التطبيق |
| النسخ الاحتياطي | تصدير/استيراد مع المرفقات، تشفير AES-256-GCM، تحقق SHA-256، ملخص قبل الاستيراد، دمج آمن |
| PWA | قابل للتثبيت، يعمل دون اتصال، إشعار عند توفر إصدار جديد |

## التشغيل محليًا

المتطلبات: Node.js 20.19+ (يُفضّل 24).

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5173`.

## القيود المعروفة

- البيانات محلية لكل متصفح ولا تتزامن تلقائيًا.
- تسجيل الدخول محلي (ليس مصادقة خادمية). نسيان كلمتي المرور معًا يعني فقدان البيانات المحلية إلا من نسخة احتياطية.
- التنبيهات لا تصل عندما يكون التطبيق مغلقًا بالكامل.
- المساعد الذكي يعمل بالنسخ واللصق مع Gemini (لا مفاتيح في الواجهة).
